# AvatarSample_D（Darkness）

原模型由 pixiv Inc. 的 VRoid Project 制作，内嵌元数据作者为「VRoidプロジェクト」，模型标题为「AvatarSample_D」，许可为 CC0 1.0。

- [VRoid Hub 官方角色页](https://hub.vroid.com/en/characters/675572020956181239/models/6535695942068248968)
- [VRoid 官方 CC0 说明](https://vroid.pixiv.help/hc/en-us/articles/360012381793)
- [CC0 1.0 通用许可](https://creativecommons.org/publicdomain/zero/1.0/)
- [原版样例的 VRM 导出文件镜像](https://opengameart.org/node/170868)

镜像压缩包为 `avatarsample_d_darkness.zip`，文件为 `AvatarSample_D_Darkness.vrm`。
VRM 原文件 SHA-256 为 `037951ea624ff5ab8ef302e00abe74edfe823f381f009a8455f962e62357d42a`。
`darkness-rig.glb` 转换自上述文件，保留原始网格、贴图和蒙皮骨骼数据。
游戏内调整了角色方向、身高和装备挂点，自有动作系统驱动骨骼。导入脚本位于 `native/tools/import-avatar.cjs`。
