# 远境与行囊素材授权

`icons/Way_*.png`、`icons/House_*.png` 和 `icons/Hearth_*.png` 是本项目原创工具、材料、弹药、构件、农作与料理图标。房屋构件、风羽鸡、岩羊、白尾鹿和炉具也由本项目程序化建模。

下列第三方素材按 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 提供。模型在游戏内做了尺寸、朝向和摆放调整，图标按界面尺寸缩放。

| 作者 | 素材 | 本地内容 |
| --- | --- | --- |
| Kit | [2D RPG Item Icons](https://opengameart.org/content/2d-rpg-item-icons) | `icons/` 的矿石、宝石、木料、蓝色与银色装备图标 |
| Drummyfish | [Fantasy RPG Icons](https://opengameart.org/content/fantasy-rpg-icons-0) | `icons/icon_*.png` 的斧、书、盾、药剂、戒指等图标 |
| mabaci | [Medieval Items](https://opengameart.org/content/crates-chests-coins-and-barrels-collection) | `models/` 的 `barrel`、`chest`、`chest_open`、`coin_stack`、`crate_small` |
| Kenney | [Nature Kit](https://kenney.nl/assets/nature-kit) | `models/nature-kit-*.glb` 的树、岩块和崖石 |
| Kenney | [Castle Kit](https://kenney.nl/assets/castle-kit) | `models/castle-kit-*.glb` 的塔楼、墙柱及桥件 |
| Kenney | [Pirate Kit](https://kenney.nl/assets/pirate-kit) | `models/pirate-kit-*.glb` 的棕榈及砂岩 |
| Kenney | [Mini Dungeon](https://kenney.nl/assets/mini-dungeon) | `models/mini-dungeon-*.glb` 的箱和桌 |

Kenney 的单体 GLB 下载使用 [Tiny Game Engine 的公开资源镜像](https://github.com/Hidencod/tge-assets)，作者与授权以上游页面为准。
